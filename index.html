Så skickar du Jumbotron som NDI

URL-parametrar: ?bg=transparent, ?bg=green (chroma key), ?bg=000000 (valfri färg). Allt ritas i 1920×1080 och skalas till fönstret.

vMix: Add Input → Web Browser → klistra in länken, storlek 1920×1080 → slå på NDI-utgång (Settings → Outputs/NDI). Transparens följer med.
OBS: Browser Source, 1920×1080, klistra in länken → skicka ut med tillägget DistroAV (NDI).
NDI Screen Capture: öppna sidan i helskärm (använd ?bg=black eller green, transparens går inte via skärmfångst).

Obs: sidorna läser matchläget från webbläsarens lokala lagring. vMix/OBS har egen webbläsare med egen lagring och ser därför inte Klocka förrän nätverkssynk finns. Idag: kör sidan i samma Chrome-profil som Klocka på samma dator och använd NDI Screen Capture.
